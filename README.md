---

## Overview

Three assignments covering core numerical methods used in data analysis and dimensionality reduction, implemented in **MATLAB** and documented with **LaTeX** reports.

---

## Assignment 1 — Principal Component Analysis (PCA)

Implementation and analysis of PCA from scratch, covering:
- Covariance matrix computation and eigendecomposition
- Explained variance analysis and scree plots
- Low-rank approximation and reconstruction error
- Visualisation of principal components on real datasets

---

## Assignment 2 — Clustering Methods

Numerical implementation and comparison of clustering algorithms:
- K-means clustering with convergence analysis
- Hierarchical clustering (linkage methods)
- Cluster validation metrics
- Visual comparison of clustering results

---

## Assignment 3 — LDA & NMF Methods

- **Linear Discriminant Analysis (LDA):** dimensionality reduction for classification, Fisher's criterion, within/between-class scatter matrices
- **Non-negative Matrix Factorisation (NMF):** multiplicative update rules, convergence behaviour, parts-based representation
